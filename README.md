# CRUD BASICO EM PHP

Feito em PHP + MYSQL para ensino de aula de programação.
CRUD de escola para cadastro de alunos (nome e idade). 

Para rodar esse código, é necessário instalar o PHP e o MySQL
Workbemch.

Depois de instalado, gere o comando no terminal do VSCode 
php -S localhost:8084.
